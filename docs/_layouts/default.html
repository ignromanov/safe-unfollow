{%- comment -%} Vercel serves this site with trailingSlash: false, so /docs/faq/ 308-redirects to /docs/faq. Jekyll's pretty permalinks end in a slash, so page.url alone would point every canonical at a URL that redirects away from itself. Strip it. {%- endcomment -%} {%- capture canonical_path -%}{{ site.baseurl }}{{ page.url }}{%- endcapture -%} {%- assign canonical_last = canonical_path | slice: -1 -%} {%- if canonical_last == '/' -%} {%- assign canonical_trimmed = canonical_path | size | minus: 1 -%} {%- assign canonical_path = canonical_path | slice: 0, canonical_trimmed -%} {%- endif -%}
