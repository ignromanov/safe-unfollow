The product mark: a shield with a check cut out, white on the brand gradient, from `src/components/Logo.tsx` (inline SVG, 512 box, `rx` 112, which is `radius-logo`).

The consumer provides `size` in px (default 40) and an optional class. Use it in the header, footer and footer CTA beside the wordmark: "SafeUnfollow" in `display` 800 and ".app" in `primary-strong`. Gradient stops are `brand-start`, `brand-mid`, `brand-end` at 135° with a faint white sheen at the top left. Never recolour, crop the shield or put it on a gradient. The file versions live in `assets/Logos`.

Static rendition: the same path as the source, drawn as an SVG symbol.
