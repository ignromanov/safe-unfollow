# Backup — Claude Design project `5e633d36-642a-4605-8000-3ecc1eecb00c`

This directory is a **copy of the hand-authored files** in the SafeUnfollow Claude Design
project. Nothing here is generated by this repo, and nothing here is read by the app or the
build — it exists because these files previously existed only in the cloud project, protected
by one rule written in `.design-sync/NOTES.md`, a file that was itself lost on 2026-08-20 when
a git worktree was removed.

## What is here, and what is not

Backed up (43 files): `foundations/` (18 specimen cards) · `catalog/` (5 variant grids) ·
`ui_kits/app/` (6, the click-through app recreation) · `handoff/` (2 conversion-redesign
documents) · `templates/conversion-audit/` (4 mockups + their loader and runtime) ·
six root text files.

Not backed up, deliberately:

- **`assets/` (8 files)** — every one has a local source already, in `public/` or
  `designs/screenshots/`. Verified 2026-08-20, file by file.
- **Everything the converter generates** — `components/`, `_preview/`, `_vendor/`, `fonts/`,
  `guidelines/`, `styles.css`, `README.md`, `_ds_bundle.*`, `_ds_sync.json`. These are rebuilt
  from this repo by `.design-sync/tools/preflight.sh` plus `package-build.mjs`; copying them
  would be storing a stale duplicate of something derivable.

## `support.js` is vendored, not ours

`templates/conversion-audit/support.js` is Claude Design's own runtime, marked
`GENERATED from dc-runtime/src/*.ts — do not edit`. It is kept because it is what parses
`<x-dc>`: without it the four `.dc.html` mockups beside it do not render at all. Do not edit it
and do not treat it as project code.

## Refreshing this copy

There is no automated sync. Re-fetch with the `DesignSync` tool (`get_file` per path) when the
project's hand-authored files change — `list_files` minus the generated set above gives the
current list, which is more reliable than any list written down here or in `NOTES.md`.

⛔ Nothing in this directory should ever be uploaded back. The design project is the live copy;
this is a one-way backup.
